Launch a niche directory in days, with paid listings built in

DirKit is a Next.js starter kit for directory websites. Auth, listings, featured placements, an admin panel and SEO are planned for v1, so you can spend your time on the niche and the audience.

We only use your email to tell you about DirKit. No spam, and you can ask to be removed at any time.

Building a directory from scratch takes longer than it looks

Every directory needs the same groundwork: user accounts, a listing submission flow, payments for featured spots, an admin area to review entries, and SEO so people can find it. DirKit packages that groundwork so you do not rebuild it for each new niche.
